# 0.2.5 / WorldBoss 0.2.0

- Fixed runtime classes sharing a declared Mixin implementation package and initialized FantasyHub items before native class icon parsing.
- Added permanent UUID class entitlements, first free choice, free owned-class switching and BeastCoin-only cooldown bypass. Preserved native class levels, allocations, skills, unlocks and Sigil data.
- Added BEconomy dual-currency class/item/bundle commerce with server-authored quotes, validation, transaction journals, rollback/reconciliation and durable mail delivery.
- Added the interactive Fantasy HUD shop with actual item previews, confirmation, balances and seven categories; no Card World products.
- Added separate personal arena reservations, tickets, encounter snapshots, reconnect grace, owner restrictions and unchanged Infinity loot probabilities.
- Polished Thanos/Collector mechanics, telegraphs, cover checks, phase warnings, safe cleanup, bounded minions and exception isolation. Increased default boss damage by 15%.
- Fixed active Stone/ticket/catalyst use being swallowed by optional accessory auto-equip callbacks; functional equipped Stones grant powers without cosmetic-slot bonuses.
- Added durable Infinity loot rolls, all six Stones, original supplied Thanos skin and Endgame Gauntlet/Stone assets, and self-contained SNAP animation with all ten outcomes.
- Persisted native party/PC faint writes and pre-mutation backups. Prevented automatic Pokédex store rescans from undoing SNAP losses.
- Added configurable Friendly/Neutral/Hostile temperament and temporary RPG-only wild HP scaling.
- Replaced Strange/Flash silhouettes with full translucent player skin/suit models including heads and capes. Fixed GUI double blur. Sling Ring now uses a safe eye ray up to 15 blocks, permits air destinations and lasts 20 seconds by default.
- Enabled native standard-template upgrades for generated hero armor so purchased catalysts can upgrade existing and newly granted suits.
- Added native mana/stamina attributes, each capped at 50 allocations with +5 maximum resource per point.
